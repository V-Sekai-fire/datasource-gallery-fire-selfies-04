# datasource-gallery-fire-selfies-04

One part of a split photo gallery of iFire's selfies and stickers, built into a static web gallery.

## What it is for

The images sit in albums under `gallery/`, and the gallery workflow builds them into a static site and publishes it to the repository's pages.

## Build

```sh
thumbsup --config config.json
```
